🔐 Drive Authorization Guide

ℹ️ One-Time Setup

This authorization is required only once to enable backup features. It allows the system to create and manage backup files in your Google Drive.

📋 Step-by-Step Instructions

Step 1: Open Apps Script Editor
  • In your Google Sheets menu, click Extensions
  • Select Apps Script from the dropdown
  • A new tab will open with the script editor
Step 2: Select Authorization Function
  • At the top of the editor, find the function dropdown (shows "Select function")
  • Click it and select authorizeDriveAccess
Step 3: Run the Function
  • Click the Run button ▶️ (looks like a play button)
  • A permission dialog will appear
Step 4: Grant Permissions
  • Click Review permissions
  • Select your Google account
  • Click Advanced (if you see a warning)
  • Click Go to [Your Project Name] (unsafe)
  • Click Allow to grant Drive access
Step 5: Verify Success
  • Check the execution log at the bottom of the Apps Script editor
  • You should see "✅ Drive access authorized successfully!"
  • Close the Apps Script tab and return to this page
  • Click the 🔄 Refresh button to reload backup statistics
✅ What Happens Next?

After authorization, a folder called SMS_Backups will be created in your Google Drive. All backup files will be stored there automatically.

⚠️ Troubleshooting

If you still see authorization errors after following these steps:

  • Make sure you selected the correct Google account
  • Try refreshing the page and running the authorization again
  • Check that pop-ups are not blocked in your browser
  • See BACKUP_AUTHORIZATION_GUIDE.md for detailed troubleshooting
